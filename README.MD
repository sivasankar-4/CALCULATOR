# Calculator App

A simple web calculator built using HTML, CSS, and JavaScript that performs basic arithmetic operations like addition, subtraction, multiplication, and division.
This project demonstrates DOM manipulation, event handling, and basic JavaScript logic to create an interactive user interface for calculations.


## Features
- Addition, Subtraction, Multiplication, Division
- Decimal number support
- Clear (C) and Delete (DEL) functions
- Operator display while typing
- Division-by-zero handling

## Technologies Used
- **HTML**
- **CSS** 
- **JavaScript**
